# Как запустить Алису AI — подробная инструкция

Проект: `alisa-activity/` (backend + frontend). Всё запускается на твоей машине.

---

## ШАГ 0. Что нужно установить (один раз)

| Что | Зачем | Как |
|---|---|---|
| **Python + uv** | бэкенд | у тебя уже есть uv |
| **Node.js** | фронтенд | у тебя уже есть |
| **FFmpeg** ⚠️ | озвучка в голосовом канале — без него бот не заговорит | открой PowerShell от админа: `winget install Gyan.FFmpeg` , потом ПЕРЕЗАПУСТИ терминал |
| **cloudflared** | чтобы Discord видел страницу Activity | скачай exe: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/ → положи например в `C:\tools\cloudflared.exe` |

Проверка: в НОВОМ терминале `ffmpeg -version` и `cloudflared --version` должны что-то ответить.

---

## ШАГ 1. Настройки Discord-приложения (один раз)

1. https://discord.com/developers/applications → твоё приложение бота.
2. **Bot**: включить `MESSAGE CONTENT INTENT`, `SERVER MEMBERS INTENT`, `PRESENCE INTENT`.
3. **Activities** (в левом меню): включить Activity, задать URL Mapping:
   - `/` → URL туннеля из ШАГА 4 (пропишешь, когда получишь ссылку)
4. Токен бота уже лежит в `backend/env/.env` (DISCORD_BOT_TOKEN, GEMINI_API_KEY).

---

## ШАГ 2. Запустить бэкенд

Открой терминал, вставь одной строкой:

```
cd "C:\Users\kocha\.zcode\workspace\draft-7b3adcf2-3b28-4767-8ca4-f777ece6a552\alisa-activity\backend"
start.bat
```

`start.bat` сам создаст venv через uv, поставит зависимости и запустит бота.
В консоли появится `Alisa AI online` и `Activity bridge: ws://127.0.0.1:8765/ws`.
Это окно держать открытым.

## ШАГ 3. Запустить фронтенд

Второй терминал:

```
cd "C:\Users\kocha\.zcode\workspace\draft-7b3adcf2-3b28-4767-8ca4-f777ece6a552\alisa-activity\frontend"
start.bat
```

Сайт поднимется на http://127.0.0.1:5173 — можно открыть прямо в браузере
и потрогать модельку уже сейчас (мост подключится автоматически).

## ШАГ 4. Туннели для Discord Activity

Discord открывает Activity только по https. Провайдер режет cloudflared
(порты 7844 к Cloudflare edge), поэтому используем **localhost.run** —
бесплатно, без регистрации, через SSH (проверено, работает).

Два туннеля (два терминала, держать открытыми):

Терминал 3 (страница):
```
ssh -R 80:127.0.0.1:5173 nokey@localhost.run
```
Терминал 4 (мост; https-страница не может открывать локальный ws://):
```
ssh -R 80:127.0.0.1:8765 nokey@localhost.run
```

В выводе каждого ищи строку вида:
`ebbdd39e943167.app.lhr.life tunneled with tls termination` — это и есть URL.

## ШАГ 5. Связать всё

1. В `frontend/.env.local` пропиши мост (ссылка из Терминала 4, **с `/ws`):
   ```
   VITE_BRIDGE_URL=wss://4939fe51a58dcd.app.lhr.life/ws
   ```
2. Перезапусти Терминал 2 (фронтенд).
3. Discord Developer Portal → Activities → URL Mapping: `/` → ссылка из Терминала 3.
4. Подожди ~1 минуту на применение URL.

⚠️ Домены localhost.run периодически ротируются — если Activity перестала
открываться, перезапусти туннели и обнови `.env.local` + URL Mapping.

## ШАГ 6. Поехали

1. Зайди в голосовой канал на своём сервере.
2. Напиши `/join` — Алиса подключится и поздоровается.
3. Открой Activity (значок ракеты 🚀 в панели голосового канала) — увидишь модельку.
4. Скажи: **«helper, как дела?»** — Алиса ответит голосом, моделька зашевелит губами.
5. Прервать ответ: слово **«стоп»** голосом / в чат / кнопка ■ / клавиша **Space**.

⚠️ Ссылки trycloudflare меняются при перезапуске туннелей — тогда повтори ШАГ 5.

## Что можно в Activity

- **Гладить волосы**: зажми ЛКМ и води по волосам → умиление + реплики («мур~»)
- **Тыкать в лицо/щёки**: 1–2 раза → смущение, 3+ → злится
- **Субтитры** ВКЛ/ВЫКЛ (клавиша S)
- **История** диалога (клавиша H) — шторка справа
- **Настройки**: голос (Светлана/Дарья), фон (прозрачный/тёмный/уютный), очистка памяти
- **Громкость** — слайдер внизу
- **Визуализатор голоса** справа танцует, пока Алиса говорит
- **Статус-бейдж**: на связи / слушаю / думаю / отвечаю / на паузе
- Счётчик вопросов ♥ в шапке

## Команды бота (только две)
- `/join` — позвать в голосовой канал
- `/leave` — отключить

## Если что-то не так

| Симптом | Причина / лечение |
|---|---|
| Бот молчит, в логах про ffmpeg | FFmpeg не установлен или терминал не перезапущен после установки (ШАГ 0) |
| Моделька есть, но «нет связи» (красная точка) | Не запущен бэкенд (ШАГ 2) или неверный VITE_BRIDGE_URL (ШАГ 5.1) |
| Activity не открывается / белое окно | URL Mapping в портале не обновлён под текущий туннель |
| Алиса не слышит | Скажи слово целиком: «helper»; проверь что бот в канале (/join) |
| Гонит два ответа подряд | Так не бывает — во время ответа ввод игнорируется; скажи «стоп» |
